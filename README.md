# OpenPrintHQ legal terms

The current text of the **OpenPrintHQ Installer License Agreement**, `installer-license.md`.

The OpenPrintHQ installer reads the agreement from this repository, so the terms can change without a new
installer release. A changed text binds a user only once they accept it: the installer shows the new version
and asks for acceptance before it goes on.

Version 4 renames the product from ArtisanHub to OpenPrintHQ; its terms are otherwise those of version 3.
Version 5 is version 4 without the note that it was a draft.

The OpenPrintHQ hub (`norjms/openprinthq`) and farm (`norjms/openprinthq-farm`) are free software
